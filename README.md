# 🔍 INLIFE - Follow Control

Instagram hesap analizi ve karşılıklı takip kontrolü için geliştirilmiş, tamamen yerel çalışan gizlilik odaklı masaüstü uygulamasıdır.

---

## 📥 Sürümler ve İndirme

Projenin ihtiyaç duyduğunuz sürümünü aşağıdaki bağlantılardan hemen indirebilirsiniz:

### 🚀 v2.0.0 (Electron Sürüm - Önerilen)
> Modern arayüz, NSIS kurulum sihirbazı (`Setup.exe`) ve gelecekteki güncellemeler için otomatik güncelleme (auto-update) altyapısına sahip yeni nesil sürüm.
- **Özellikler:** Akıcı arayüz, otomatik güncelleme, profesyonel kurulum.
- **İndir:** [INLIFE Follow Control v2.0.0 Releases](https://github.com/INLIFEproduction/INLIFE---Follow-Control/releases/tag/v2.0.0)

### 📦 v1.0.0 (Python Standalone Sürüm)
> Kurulum gerektirmeyen, doğrudan tekil `.exe` dosyası şeklinde çalışan ilk kararlı çevrimdışı sürüm.
- **Özellikler:** Saf Python altyapısı, kurulumsuz taşınabilir kullanım.
- **İndir:** [INLIFE Follow Control v1.0.0 Releases](https://github.com/INLIFEproduction/INLIFE---Follow-Control/releases/tag/v1.0.0)
